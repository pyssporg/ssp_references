# Product-breakdown maintenance

- **Current state**: layer leaves hold present-tense facts.
- **History**: dated decisions live in `docs/archive/archive.zip`.
- **Read history**: `pb archive list` then `pb archive read <ID>`.
- **Add a record**: `pb archive add <record>`.
- **Registers**: `docs/archive/README.md`, `docs/archive/design-choice-log.md`, and `docs/archive/traceability-map.md` are generated by `pb registers --root docs/breakdown`.
- **Checks**: run `pb check --strict` and `pb node-size --strict` after edits.
- **Config**: `docs/breakdown/pb.toml`.
- **Forbidden**: per-layer `decisions/` folders and hand-edited registers.
