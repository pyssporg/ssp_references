# GainOffset — FMU definition

## Provenance

This directory holds the FMU *definition* for `GainOffset`, generated by
`pyfmi_sysml2` 0.1.0 from
`models/ssp/GainOffset/architecture/GainOffset.sysml`.

- `fmu/modelDescription.xml` and `fmu/sources/*.h` are generated text.
- `src/GainOffset.c` implements the generated FMI 2.0 CoSimulation interface.
  `include/fmi2*.h` are the FMI standard headers copied verbatim from the
  vendored `pyssp_standard` tree, `3rdParty/FMI2/headers/`.
- There is no binary here, so this directory is not loadable as an FMU on its
  own. The built FMU is `artifacts/build/GainOffset/Generator.fmu`.

## Rebuild

`./venv/bin/python scripts/build_models.py run GainOffset`

The build regenerates this definition, compiles
`artifacts/build/GainOffset/Generator.so`, packages
`artifacts/build/GainOffset/Generator.fmu`, and only then exports the SSP. The
system, its analyses, and the end-to-end provenance live in
`models/ssp/GainOffset/FIXTURE.md`.

## Determinism

`generation_time` is injected as `2026-01-01T00:00:00Z`, and the `guid` is the
uuid5 derived from `System.Generator`. Two consecutive rebuilds produce an
identical `fmu/` tree and a byte-identical archive on the same toolchain.
