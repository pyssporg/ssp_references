# GainOffset — FMU source

## Provenance

This directory holds the authored FMU *source* for `GainOffset`. The FMI
definition is generated by `pyfmi_sysml2` 0.1.0 from
`models/ssp/GainOffset/architecture/GainOffset.sysml`.

- `src/GainOffset.c` implements the generated FMI 2.0 CoSimulation interface.
- The generated C interface headers and `modelDescription.xml` are build
  outputs under `artifacts/build/GainOffset/`; the FMI 2.0 standard headers
  come from `pyfmi_sysml2.fmi2_headers()`.
- There is no binary and no definition text here, so this directory is not
  loadable as an FMU on its own. The committed
  `artifacts/build/GainOffset/Generator.fmu` archive is the definition copy
  consumers read.

## Rebuild

`./venv/bin/python scripts/build_models.py run GainOffset`

The build writes the C interface headers and `modelDescription.xml` to
`artifacts/build/GainOffset/`, compiles
`artifacts/build/GainOffset/Generator.so`, packages
`artifacts/build/GainOffset/Generator.fmu`, and only then exports the SSP. The
system, its analyses, and the end-to-end provenance live in
`models/ssp/GainOffset/FIXTURE.md`.

## Determinism

`generation_time` is injected as `2026-01-01T00:00:00Z`, and the `guid` is the
uuid5 derived from `System.Generator`. Two consecutive rebuilds produce an
identical definition set (headers and `modelDescription.xml`, `sha256sum` per
file) and a byte-identical archive on the same toolchain.
