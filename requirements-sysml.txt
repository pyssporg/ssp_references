# Standalone SysML tool environment.
#
# The round-trip checker invokes this environment's `pyssp` executable and
# exchanges only SSD artifacts, so this environment can pin different library
# versions from the runtime venv.
#
#   python3 -m venv venv-sysml
#   venv-sysml/bin/pip install -r requirements-sysml.txt
#
# Only the two distributions behind the `pyssp` CLI are needed here. They come
# from the same release wheels as the runtime (pinned directly below).
#
# The vendored 3rd_party/pyssp_workflow tree is gone. For cross-repo development
# in the flat ecosystem workspace (pyssp_dev/repos/), install the siblings as
# editable checkouts instead -- each sits one level above this repository's root:
#
#   python3 -m pip install -e ../experimental_pyssp_standard
#   python3 -m pip install -e ../pyssp_sysml2
#   python3 -m pip install -e ../pycps_sysml2
#   python3 -m pip install -e ../pyfmi_sysml2
experimental-pyssp-standard @ https://github.com/pyssporg/experimental_pyssp_standard/releases/download/v0.9.3.dev0/experimental_pyssp_standard-0.9.3.dev0-py3-none-any.whl
pyssp-sysml2 @ https://github.com/pyssporg/pyssp_sysml2/releases/download/v0.5.0/pyssp_sysml2-0.5.0-py3-none-any.whl
