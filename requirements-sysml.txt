# Standalone SysML tool environment.
#
# The round-trip checker invokes this environment's `pyssp` executable and
# exchanges only SSD artifacts, so this environment can pin different library
# versions from the runtime venv.
#
#   python3 -m venv venv-sysml
#   venv-sysml/bin/pip install -r requirements-sysml.txt
#
# Only the two distributions behind the `pyssp` CLI are needed here. They come
# from the same release wheels as the runtime; the SysML tree and the
# experimental_pyssp_standard fork layer on top as editable checkouts.
experimental-pyssp-standard @ https://github.com/pyssporg/experimental_pyssp_standard/releases/download/v0.9.2.dev0/experimental_pyssp_standard-0.9.2.dev0-py3-none-any.whl
pyssp-sysml2 @ https://github.com/pyssporg/pyssp_sysml2/releases/download/v0.3.0/pyssp_sysml2-0.3.0-py3-none-any.whl
-e ./3rd_party/pyssp_workflow/3rd_party/experimental_pyssp_standard
-e ./3rd_party/pyssp_workflow/3rd_party/pyssp_sysml2
