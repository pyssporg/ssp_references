# Standalone runtime environment. The six vendored pyssp distributions install
# as PEP 508 direct references to their GitHub release wheels:
#
#   * each tree's release workflow (.github/workflows/wheels.yml) attaches the
#     asset, and the release tag is always v<version>;
#   * an unreleased tag makes this install fail (404) instead of silently
#     resolving an older build — bump the tag and the filename together.
#
# For editable checkouts of the same trees (development) install
# requirements-dev.txt instead.
