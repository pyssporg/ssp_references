# Standalone runtime environment. One pyssp bundle installs the whole stack:
#
#   pyssp-workflow
#
# The bundle exposes no optional dependency groups beyond its development one:
# the SysML bundle and the flow engine are base dependencies, so a plain
# install is complete. This one direct reference transitively pins the eight
# pyssp and SysML distributions: six capability libraries
# (experimental-pyssp-standard, pyssp-workflow, pyssp-simulate, pyssp-sysml2,
# pyssp-vv, sequence-extensions-flow) plus the SysML dialect (pycps-sysml2) and
# FMI artifact (pyfmi-sysml2) libraries. Each arrives as a PEP 508 direct
# reference to a GitHub release wheel named by the wheel's metadata; the
# release tag is always v<version>, so an unreleased tag fails the install
# (404) instead of silently resolving an older build.
#
# For editable checkouts of the same trees (development) install
# requirements-dev.txt instead. The third-party runtime dependencies below are
# unchanged.
pyssp-workflow @ https://github.com/pyssporg/pyssp_workflow/releases/download/v0.3.0/pyssp_workflow-0.3.0-py3-none-any.whl
